# Personal Portfolio

My personal developer portfolio showcasing selected full-stack projects, engineering philosophy, and professional experience.

## 🎯 Purpose

This portfolio serves as a curated showcase of my strongest engineering projects, focusing on full-stack development, clean architecture, and DevOps practices.

Rather than listing all academic work, the goal is to highlight production-oriented systems and real-world problem solving.

---

## 🛠 Tech Stack

- Next.js / React
- TypeScript
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

---

## ✨ Features

- Responsive, performance-optimized design
- Accessible keyboard navigation
- Animated project carousel
- Light theme with custom design system
- Clean, minimal aesthetic

## 🧠 Engineering Focus

The portfolio emphasizes:

- Performance optimization
- Accessibility (ARIA, keyboard support)

- Clean code structure
